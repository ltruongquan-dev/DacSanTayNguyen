# Dự án Đặc sản Tây nguyên

Dự án này nhằm tạo ra một web để bán các món ăn địa phương và các món ăn đóng hộp mang đi.

**Cùng tham gia làm nhóm với các thành viên giúp tăng khả năng làm việc nhóm**

## Nhóm trưởng: Lê Trường Quân

- Nhiệm vụ: Quản lý Git Repository, viết tài liệu hướng dẫn và xây dựng cấu trúc dữ liệu nền tảng [products.json](products.json)

## Thành viên 1: Diệu Linh

- Xây dựng cấu trúc HTML & CSS cho trang chủ [index.html](index.html), [homepage.htm](homepage.html), [CSS/style.css](CSS/style.css)
- Thiết kế bố cục các thẻ sản phẩm.

## Thành viên 2: Thu Hiền

- Hoàn thiện trang liên hệ [contact.html](contact.html),[CSS/contact.css](CSS/contact.css)
- Thiết lập các liên kết điều hướng và chuẩn bị logic JavaScript [main.js](main.js).

# 🟨Cấu trúc thư mục dự án

dac_san_tay_nguyen/
│
├── CSS/
│ ├── style.css # CSS chính cho toàn bộ trang web & trang chủ
│ └── contact.css # CSS riêng cho trang Liên hệ
│
├── asset/ # Thư mục chứa tài nguyên hình ảnh sản phẩm
│
├── index.html # Trang chủ hiển thị danh sách sản phẩm đặc sản
├── homepage.html # Trang chủ phụ
├── contact.html # Trang liên hệ nhận phản hồi từ khách hàng
├── main.js # File JavaScript khởi tạo tính năng động sau này
├── products.json # File cấu trúc dữ liệu sản phẩm dạng JSON
└── README.md # Tài liệu hướng dẫn này
